## О проекте

Заказчик планирует выйти на онлайн-рынок с конкурентоспособными и востребованными сборками персональных компьютеров.

Цель проекта — исследовать рынок, выявить характеристики, связанные с продажами и стоимостью компьютеров, и построить модель прогнозирования цены.

### Задачи исследования

**1 — Анализ факторов продаж**

Регрессионный анализ взаимосвязей между количеством продаж, ценой и техническими характеристиками компьютеров. Основной акцент — интерпретация коэффициентов и статистическая значимость факторов, а не прогнозирование продаж новых товаров.

**2 — Прогнозирование стоимости**

Построение модели линейной регрессии для оценки цены компьютера на основе его характеристик.

В ходе предобработки были обработаны пропуски, дубликаты и аномальные значения, разобраны вложенные структуры признаков и унифицированы категориальные данные.

После очистки в исследовании осталось **1 853 наблюдения**.

## Методология

Исследование включало несколько этапов:

- **Подготовка данных:** обработка пропусков, дубликатов и аномальных значений, разбор вложенных структур и унификация характеристик.
- **Разведочный анализ:** изучение распределений и взаимосвязей между переменными.
- **Статистический анализ:** проверка гипотез, исследование мультиколлинеарности с помощью VIF и анализ статистических связей.
- **Подготовка признаков:** преобразования Box–Cox и Yeo–Johnson, сглаженное кодирование категориальных переменных методом target encoding.
- **Моделирование:** построение регрессионных моделей, интерпретация коэффициентов и оценка качества прогноза цены.

## Результаты моделирования

### Прогнозирование цены

Для оценки стоимости компьютеров построена модель линейной регрессии.

| Метрика | Результат |
|---|---:|
| R² на исходной шкале цены | 0,784 |
| MAE | 9 985,59 ₽ |
| RMSE | 17 833,63 ₽ |
| R² на преобразованной шкале целевой переменной | 0,891 |

R² = 0,891 получено на преобразованной шкале целевой переменной, поэтому напрямую сравнивать его с R² на исходной шкале цены некорректно.

### Факторы, связанные с ценой

В ходе исследования с ценой компьютера были заметно связаны:

- характеристики видеопроцессора;
- объём SSD и HDD;
- тип и количество ядер процессора;
- объём оперативной памяти;
- гарантийный срок;
- продавец.

### Анализ продаж

Регрессионная модель использовалась для изучения статистических взаимосвязей между продажами, ценой и характеристиками компьютеров. Эта часть исследования ориентирована на интерпретацию факторов, а не на построение отдельной системы прогнозирования продаж.

## Практическое применение

Результаты исследования могут использоваться как аналитическая основа для формирования ассортимента и позиционирования компьютерных сборок:

- оценивать связь технических характеристик со стоимостью;
- сравнивать конфигурации компьютеров;
- учитывать особенности продавца и ценовое позиционирование;
- определять характеристики, на которых стоит делать акцент в карточках товаров.

Полученные зависимости отражают статистические связи в исследуемой выборке и не доказывают причинно-следственные отношения. Перенос результатов на другие площадки и периоды требует дополнительной проверки.

## Запуск проекта

Для воспроизведения исследования потребуются Python, Visual Studio Code с расширениями Python и Jupyter, а также файл с исходными данными.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/artemsekta/pc-market-analysis.git
cd pc-market-analysis
```

### 2. Установить расширения VS Code

Расширения можно установить через терминал:

```powershell
code --install-extension ms-python.python
code --install-extension ms-toolsai.jupyter
```

Либо через панель Extensions в Visual Studio Code, найдя расширения **Python** и **Jupyter**.

### 3. Создать виртуальное окружение

```bash
python -m venv .venv
```

Активировать окружение в Windows:

```powershell
.venv\Scripts\Activate.ps1
```

В Linux или macOS:

```bash
source .venv/bin/activate
```

### 4. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

### 5. Открыть проект в VS Code

```bash
code .
```

Открыть файл `analysis.ipynb`. Если VS Code не выбрал виртуальное окружение автоматически, нажать **Select Kernel** в правом верхнем углу ноутбука и выбрать интерпретатор Python из `.venv`.

После выбора ядра последовательно выполнить ячейки ноутбука.

Для воспроизведения исследования необходим файл `data/wb_pc_hard.csv`, расположенный по пути, который используется в ноутбуке.

## Ограничения

- В исходном датасете присутствуют пропуски и неоднородно записанные значения.
- Временной период сбора данных не указан.
- Результаты относятся к исследуемой выборке и требуют дополнительной проверки при переносе на другие условия.
- Модель прогнозирования цены предназначена для аналитической оценки и не является готовой системой автоматического ценообразования.
